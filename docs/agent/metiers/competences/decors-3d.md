## Compétence : décors 3D (Plateau, Studio virtuel)

- **Bâtiments et rues** : l'add-on libre Building Tools (MIT) génère façades, étages, fenêtres et toits dans
  Blender ; sinon des kits modulaires (Poly Haven, Poly Pizza) alignés sur une grille de 1 m.
- **Échelle** : 1 unité = 1 m ; une porte fait 2,1 m, un étage 3 m ; le personnage sert d'étalon.
- **Lisibilité** : trois plans de profondeur (avant, sujet, fond) ; le fond moins contrasté ; une couleur d'accent.
- **Poids** : un décor de fond n'a pas besoin de détail : densités réduites, textures partagées, instances pour les
  répétitions (gltfpack `-mi`).
- **Lumière** : HDRI Poly Haven (CC0) pour l'ambiance, puis la clé du plan ; garder la même direction de lumière
  dans tous les plans d'une séquence.
