## Compétence : illustrations 3D pour Card Forge

Un personnage ou un objet 3D devient une illustration de carte cohérente sur tout un jeu :
- **Même studio pour toutes les cartes** : même focale (50–85 mm), même hauteur de caméra, même trois-points, même
  fond ; seul le sujet change. Rendu au format de la fenêtre d'illustration du gabarit, avec une marge pour le texte.
- **Poses** : une pose par carte, lisible en silhouette à 3 cm ; l'animation faciale sert aussi à figer une
  expression (joie, colère, surprise) pour une variante de carte.
- **Séries** : le même modèle décliné (couleurs, accessoires) garde sa géométrie et ses UV ; changer les matières
  seulement.
- **Impression 3D** (socles, présentoirs, boîtes) : une pièce paramétrique se décrit mieux en code (build123d,
  Apache-2.0 : congés, booléens propres, export STL / STEP) qu'en génération IA ; épaisseurs ≥ 1,2 mm.
- Licence : un modèle importé (Sketchfab, Blender Studio) porte son crédit sur la carte ou dans le livret.
