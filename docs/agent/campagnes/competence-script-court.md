## Compétence : script court (vidéo verticale)

Trois blocs, dans cet ordre : **accroche** (3 s), **corps** (une idée par ligne), **appel** (une seule action).
- Durée : compte 2,5 mots par seconde. 30 s ≈ 75 mots, 60 s ≈ 150 mots. Annonce la durée estimée.
- Une ligne = une idée = un plan. Une ligne de plus de 12 mots se coupe en deux.
- Toutes les 3 secondes au plus, quelque chose de neuf à l'image (plan, chiffre, mot-clé) : note-le en marge.
- L'appel est unique et concret (s'abonner, commenter un mot précis, ouvrir le lien de la biographie, écrire sur
  WhatsApp) ; jamais deux appels.
- Quatre contrôles avant de rendre le script, à consigner dans `controle.md` : (1) l'accroche tient dans les 3
  premières secondes ; (2) une idée par ligne ; (3) le script finit sur l'appel ; (4) les mots à l'écran sont ceux
  qui sont dits.
- La voix est celle de l'espace : ses mots, son ton, ses mots interdits. Pas de tic de langue ni de superlatif.
