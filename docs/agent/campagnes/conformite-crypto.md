# Grille de conformité — contenus sur le jeton $DEEPOTUS

Repères à faire confirmer par un professionnel ; ce n'est pas un avis juridique. Applique-la à toute pièce
qui mentionne le jeton, son prix, un airdrop, un mint, un burn ou une plateforme d'échange.

| Contrôle | Règle |
|---|---|
| Promesse | Aucune promesse ni suggestion de gain, rendement, prix, « to the moon », « x100 », date de hausse. |
| Risque | Mention courte de risque (ex. « Crypto-actif volatil : risque de perte totale. Pas un conseil en investissement. ») sur chaque pièce. |
| Identification | La pièce est identifiable comme communication promotionnelle du projet. |
| Cohérence | Rien qui contredise le livre blanc / le site officiel ; chiffres sourcés (lien). |
| Influenceurs | Aucun créateur rémunéré pour le jeton (loi française de 2023 sur l'influence commerciale) tant que ce point n'est pas validé. |
| Publicité payante | Aucune pub payante sur le jeton (règles Meta, Google, X, TikTok). |
| Public | Rien qui vise les mineurs. |
| Séparation | Les contenus sur le logiciel DeepotusVideoGen ne promettent rien sur le jeton, et inversement. |

Toute pièce qui échoue : corrige-la ou retire-la, et note-le dans `controle.md`.
