# Dossier de campagne — modèle

Remplis ce que l'utilisateur a donné ; marque `?` ce qui manque et ne pose que les questions bloquantes.

```
Produit :            DeepotusVideoGen / $DEEPOTUS / <nouveau produit ou client>
Espace de marque :   <id de l'espace dans l'app> (deepotus par défaut)
Type :               lancement / nouvelle version / événement (airdrop, mint, burn…) / campagne longue
Objectif :           <ventes, inscriptions, membres Telegram, abonnés, notoriété> + chiffre visé
Public :             qui, où il se trouve, ce qui le fait réagir
Message clé :        une phrase
Dates :              début — fin ; temps forts datés
Canaux :             X / Telegram / Instagram / YouTube / TikTok / e-mail / page de lancement
Matière fournie :    liens du site officiel, captures, vidéos, visuels, chiffres, citations
Interdits :          mots, sujets, concurrents, promesses
Budget :             génération IA (€) / pub (€, 0 par défaut)
Contraintes :        légales, calendrier, validation par un tiers
```

Questions bloquantes typiques : l'objectif chiffré, les dates, le produit exact quand le dossier en mêle
plusieurs, et — pour le jeton — l'accord explicite sur la grille de conformité.
