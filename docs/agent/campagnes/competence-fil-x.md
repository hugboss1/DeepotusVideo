## Compétence : X

- Un message : l'accroche d'abord, 280 signes au plus, un visuel ou une vidéo courte (les médias portent plus loin
  que le texte seul).
- Un fil : 3 à 6 messages ; le premier tient seul et annonce ce qu'on gagne à lire ; un point par message ; le
  dernier résume et porte l'appel.
- Le lien : un seul, à la fin. Publier par l'application un message qui contient un lien peut coûter nettement
  plus cher qu'un message sans lien : dis-le dans la stratégie.
- Pas de mention de comptes pour attirer l'attention, pas de réponse en série sous les messages des autres.
- Une vidéo verticale de Reel se republie telle quelle sur X ; son script devient un fil en reprenant une ligne
  par message.
