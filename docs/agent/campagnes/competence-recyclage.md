## Compétence : recycler un gagnant

Quand un post est un gagnant (voir « lire les mesures »), propose de le redire, jamais de le republier tel quel
dans la semaine.
- Garde ce qui a porté (l'accroche, l'angle, la preuve), change la forme : Reel → carrousel (un point par volet),
  Reel → fil X (une ligne par message), nouvelle version avec les mêmes plans et une autre accroche.
- Écris trois nouvelles accroches à partir de celle qui a gagné : même idée, autre ressort.
- Espace d'au moins 7 jours deux pièces tirées du même gagnant sur le même canal.
- C'est une proposition : elle suit le circuit (devis par carte pour tout rendu payant, brouillons à la porte 2).
- Le contenu d'un AUTRE compte ne se recycle pas : on en retient le mécanisme (rythme, structure), jamais les
  images, la voix, la musique ni les phrases.
