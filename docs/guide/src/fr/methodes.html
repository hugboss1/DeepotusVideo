Vous saurez trouver une méthode éprouvée pour ce que vous voulez faire, la suivre pas à pas, et en parler avec l'agent métier qui la porte. L'écran et les fiches sont gratuits ; chaque message à un agent est payant, estimé avant l'envoi.

Trouver une méthode

  1. Ouvrez Méthodes dans la barre de gauche, sous la Bibliothèque : 94 recettes illustrées, de la plus utile à la moins utile.
  2. Tapez quelques mots dans Chercher une méthode… (« étalonnage », « sprite », « pub ») : la recherche lit les titres, les résumés, les étapes et les exemples, en français comme en anglais.
  3. Resserrez avec les filtres Famille, Agent et Écran ; chaque choix dit combien de méthodes il garde. Effacer les filtres revient à la galerie entière.

Suivre une fiche

  1. Cliquez une carte : la fiche s'ouvre avec ses Étapes, ses Contrôles qualité et ses Pièges à éviter, les écrans de l'application où elle se fait et les modèles cités.
  2. Suivez les étapes dans les écrans indiqués ; les contrôles disent comment savoir que le résultat est bon.
  3. Les Exemples de demandes se copient d'un clic, pour les reprendre tels quels avec l'agent.
  4. Toutes les méthodes revient à la galerie, avec les mêmes filtres.

Parler à l'agent métier

Chaque fiche est portée par un agent métier : le Monteur, le Réalisateur, le Retoucheur, les Déclinaisons produit, le Directeur d'acteurs, le Publicitaire, l'Artiste 2D, l'Artiste 3D ou l'Éditeur illustré. Il connaît ses méthodes, mesure vos fichiers et pose des gestes locaux et gratuits (couper sur la musique, graver un titre, comparer deux versions, vérifier un format).

  1. Dans la fiche, « Parler au … » ouvre la conversation sur le côté. Une clé Anthropic doit être posée dans Réglages › Clés d'API.
  2. Décrivez ce que vous voulez faire, avec le chemin de vos fichiers, ou cliquez un exemple pour remplir le champ.
  3. Estimer le coût donne le prix maximal du message, sans rien dépenser. Le bouton devient alors « Envoyer (≈ x $) » : seul ce clic dépense.
  4. La réponse montre les outils que l'agent a appelés et ce qu'a coûté le message.

La chaîne d'éditions du Monteur

Le Monteur propose une étape d'édition vidéo, une seule chose changée, en carte « Lancer (≈ x $) ». Le clic la lance ; la dérive mesurée contre la version d'avant dit si la caméra et le timing ont tenu.

L'Arbitre

Tous les agents savent comparer équitablement les sorties de plusieurs modèles : même référence, une sortie chacun, aucune écartée, rangées par note, puis coût, puis temps.

Bon à savoir

Un message est compté sous la catégorie de son agent (montage pour le Monteur, chapitres pour le Réalisateur…) et s'arrête avant de dépasser le montant accepté. L'agent ne lance jamais de génération payante : il la propose, vous la lancez.

Les méthodes s'inspirent des explorations publiques de Scenario, réécrites pour l'application : chaque fiche garde un lien vers sa source.
