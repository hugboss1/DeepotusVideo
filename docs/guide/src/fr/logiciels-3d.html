Vous saurez dire à Deepotus où sont installés Blender, Godot, Unreal Engine et Unity, vérifier leur version, et savoir ce que chacun reçoit de l'application. Cinq minutes par logiciel ; gratuit : rien n'est envoyé hors de votre PC.

Avant de commencer

Installez seulement ce dont vous vous servez : Blender 4.2 ou plus récent, Godot 4, Unreal Engine 5 (par le lanceur Epic) ou Unity (par Unity Hub). Pour les moteurs de jeu, gardez un projet sous la main : Deepotus y dépose ses ressources dans un sous-dossier à lui.

Régler un logiciel

  1. Ouvrez Réglages › Moteurs et logiciels 3D : une carte par logiciel.
  2. Cliquez Détecter. Deepotus cherche aux endroits habituels et liste ce qu'il trouve, sans rien enregistrer.
  3. Cliquez Utiliser en face du bon exécutable, puis Enregistrer. Rien trouvé : collez vous-même le chemin complet du fichier .exe.
  4. Pour un moteur de jeu, collez aussi le dossier du projet et cliquez Enregistrer à côté.
  5. Cliquez Tester : la réponse donne la version et, s'il y a lieu, le nom du projet. Rien ne s'ouvre à l'écran.

Logiciel par logiciel

Blender

Passes du plan, export et import FBX, « Ouvrir dans Blender » de l'Établi. Champ vide : Deepotus prend le Blender le plus récent de Program Files.

Blender MCP

Le pont qui laisse l'agent Réalisateur lire la scène ouverte dans Blender. Tester lance mcp-for-blender et dit si Blender répond, sans rien modifier.

Godot

SpriteFrames, TileSet, scènes .tscn et modèles .glb, déposés dans deepotus/. Le dossier du projet contient project.godot.

Unreal Engine

Modèles .glb, textures T_… et sprites Paper2D, déposés dans Content/Deepotus. La version se lit dans le moteur installé ; le dossier du projet contient le .uproject.

Unity

Modèles .glb, MaskMap et feuilles de sprites, déposés dans Assets/Deepotus. Sans le paquet glTFast dans le projet, les .glb restent inertes : Tester le signale.

Pour aller plus loin : Préparer une pièce avant le slicer, Animer des sprites, Peindre des décors en tuiles.

Bon à savoir

Unity ne donne sa version que pour un éditeur installé par Unity Hub : ailleurs, Tester le dit plutôt que de lancer Unity pour la lire.

Détecter ne fait que proposer : tant que vous n'avez pas cliqué Enregistrer, l'ancien réglage reste en place.
