Vous saurez lire une liste de modèles d'IA : quelle clé sert, combien coûte un tir, et quoi faire quand une clé manque. Cinq minutes, gratuit ; les mêmes listes servent dans toute l'application.

Deux voies pour un même modèle

Partout où l'on génère (images, vidéos, sons, détourage), la liste des modèles est rangée en groupes, un par voie. Vous gardez toutes vos clés : chaque liste propose toutes les voies, et vous choisissez modèle par modèle.

Via la clé fal

Une seule clé fal.ai ouvre la plupart des modèles : FLUX, Nano Banana, GPT Image, Seedream, Veo, Kling… Le libellé dit « via fal » quand le même modèle existe aussi en direct.

Avec votre clé

Le modèle payé directement chez son fournisseur : OpenAI, Gemini, ElevenLabs, Meshy, HeyGen. Utile si vous avez déjà un compte et des crédits chez lui.

Local, gratuit

Certains outils tournent sur votre PC, comme le détourage rembg ou le fond uni : ni clé ni dépense.

Lire le prix d'une option

Chaque option affiche son prix unitaire après le nom : $0.04/image, $0.10/s de vidéo, $0.0018/s de son, /30 images pour un détourage vidéo. Une option marquée prix à mesurer est payante, mais son tarif n'est pas encore relevé : elle n'est jamais présentée comme gratuite.

Avant un tir, l'écran affiche le prix total calculé par le serveur pour ce que vous demandez : une image et son détourage, une vidéo de 6 s… C'est ce même montant que vérifient vos plafonds, voir Maîtriser ses dépenses.

Une option « clé à ajouter »

  1. Une option dont la clé manque reste visible et choisissable ; elle porte la mention « clé … à ajouter dans Réglages ».
  2. Si vous la lancez, le tir est refusé tout de suite, avant toute dépense, avec le nom de la clé qui manque.
  3. Posez la clé dans Réglages › Clés d'API (voir Brancher ses clés) : elle sert aussitôt, sans redémarrer. Ou prenez la même option via la clé fal.

Bon à savoir

Les noms de modèles (Flux 3, Veo 3.1 Fast, Sonilo…) sont des noms propres : ils restent les mêmes en français et en anglais.

Un tir dont le prix dépasse votre plafond est refusé avant l'appel. Les actions les plus chères se lancent en deux clics : le premier affiche le devis, le second lance.
