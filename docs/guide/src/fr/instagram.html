Vous saurez relier votre compte Instagram pour que le Planificateur publie vos Reels seul et que l'onglet Croissance lise vos statistiques. Comptez trente minutes la première fois ; c'est gratuit : la documentation de Meta n'annonce pour ces appels que des limites de débit, aucun tarif.

Avant de commencer

Il faut un compte Instagram professionnel, de type créateur ou entreprise. Dans l'application Instagram : Paramètres, Type de compte, Passer à un compte professionnel. Ce passage n'oblige pas à rendre vos coordonnées publiques : laissez les options de contact vides ou masquées. Il faut aussi un compte Facebook pour ouvrir Meta for Developers (developers.facebook.com).

Le jeton que vous allez créer donne accès à votre compte. Collez-le seulement dans Deepotus, jamais dans un message, un ticket ou une capture.

Créer l'application Meta

  1. Sur developers.facebook.com, ouvrez My Apps puis Create app. Donnez-lui un nom, par exemple « Deepotus ».
  2. Choisissez le cas d'usage Gérer les messages et les contenus sur Instagram ; l'ancienne « connexion Instagram » n'est plus proposée aux applications neuves. Rattachez votre portefeuille business.
  3. Sur la page API setup with Unified login, créez la configuration à partir du modèle proposé.
  4. Cochez les autorisations : instagram_basic, instagram_content_publish, instagram_manage_insights et instagram_manage_comments. Ajoutez les messages ou la publicité seulement si vous en avez besoin.
  5. Dans les rôles de l'application, ajoutez votre compte Instagram comme testeur Instagram et acceptez l'invitation depuis ce compte. Générez ensuite le jeton de la configuration : il commence par EAA et n'expire pas. Copiez-le.
  6. Relevez l'identifiant du compte business Instagram : une suite de chiffres qui commence par 1784.

Coller le jeton dans Deepotus

  1. Ouvrez Réglages › Comptes connectés et dépliez Instagram. Pour un espace de marque précis, passez plutôt par Espaces de marque › Canaux.
  2. Collez le jeton dans IG_ACCESS_TOKEN et l'identifiant dans IG_BUSINESS_ID, puis Enregistrer à côté de chacun. Aucun redémarrage n'est nécessaire.
  3. Cliquez Vérifier les identifiants. La réponse donne votre @nom : le compte est relié. Le lien Guide du bloc ramène à la console Meta.

Lire ses statistiques

  1. Appuyez sur F1 et ouvrez l'onglet Croissance.
  2. Choisissez la période et l'espace, puis Relever maintenant. Le bloc Compte Instagram affiche les vues, la portée, les abonnés et les interactions.
  3. Une mesure que Instagram refuse reste vide, et l'écran dit combien ont été refusées.

Limites constatées

Moins de 100 abonnés

Instagram ne rend pas les arrivées et départs d'abonnés sous 100 abonnés. Les nouveaux abonnés restent vides, ce n'est pas une panne.

Posts d'avant le passage pro

Les mesures des médias publiés avant le passage en compte professionnel sont refusées (sous-code 2108006). Seuls les posts suivants sont mesurés.

Dépannage : « API access blocked. »

Si Vérifier les identifiants répond instagram 400 avec "API access blocked.", code 200 et error_subcode 5258005, c'est l'application Meta qui est bloquée, pas le Reel ni Deepotus. Deepotus l'écrit désormais en clair.

Ce que dit Meta : sa table des codes d'erreur liste 5258005 « API access blocked. » sans autre explication. Ses voisins sont 5258004, application archivée, et 5258006, application supprimée. Le blocage porte donc sur l'état de l'application, pas sur le jeton ; c'est une déduction, Meta ne l'écrit pas. Vérifiez dans cet ordre :

  1. État de l'application dans le tableau de bord Meta : alertes, mention Restreinte, Inactive ou Archivée. Une application archivée se restaure depuis My Apps, filtre Archived. Une application restreinte se conteste depuis le tableau de bord.
  2. Mode développement : seuls les comptes qui ont un rôle sur l'application y ont accès. Le compte Facebook qui a créé le jeton doit être administrateur, développeur ou testeur, et gérer la Page reliée au compte Instagram. Ne passez pas l'application en mode Live sans examen par Meta.
  3. Nouveau jeton : générez-en un depuis la configuration, collez-le, puis Vérifier les identifiants. Une application redevenue active exige des jetons neufs.

Sources : developers.facebook.com, pages « Marketing API error codes » et « App States » (lues le 13/11/2026).

Bon à savoir

Tant qu'Instagram n'est pas relié, ses posts passent en mode assisté : le Planificateur les prépare et vous les envoyez d'un clic. Voir Connecter ses comptes.

Ne donnez jamais le jeton entier à qui que ce soit, assistant compris : les premières lettres suffisent pour savoir de quel jeton on parle.
