Vous saurez poser la clé d'un fournisseur d'IA, choisir quel moteur sert à quoi, brancher un fournisseur libre ou un serveur sur votre réseau, et protéger vos clés par un mot de passe. Dix minutes, gratuit ; les clés se créent chez chaque fournisseur.

Avant de commencer

Une clé d'API est un code que le fournisseur vous donne sur son site, dans votre compte. Elle autorise l'application à travailler pour vous ; c'est lui qui facture. Une seule est indispensable pour démarrer : fal.ai.

Poser une clé

  1. Ouvrez Réglages › Clés d'API. Chaque fournisseur a sa ligne et son état : manquante tant qu'aucune clé n'est posée. Les pastilles fal, heygen et voix de l'en-tête mènent ici d'un clic.
  2. Cliquez Guide : il dit où créer la clé chez le fournisseur et comment elle est facturée.
  3. Collez la clé dans le champ, puis Enregistrer. Elle sert tout de suite, sans redémarrer.
  4. Cliquez Tester sur la ligne : le fournisseur dit s'il accepte la clé, sans rien dépenser.

Pour poser plusieurs clés d'un coup, remplissez les champs puis Enregistrer toutes les modifications.

Choisir le moteur de chaque tâche

  1. Ouvrez Réglages › Fournisseurs par défaut. Les lignes image vers vidéo, avatar et voix off disent quelle clé les sert et si elle est posée.
  2. Résumé des News et Planification des posts choisissent chacun un moteur de texte : un intégré (Anthropic, OpenAI, Gemini, Ollama), un fournisseur libre ou un serveur local. « Automatique » prend le premier moteur prêt.
  3. Plus bas, chaque moteur configuré a sa ligne Modèle par défaut : choisissez dans la liste lue chez le fournisseur, ou tapez un nom. Tester vérifie que le modèle est publié, sans rien dépenser ; Enregistrer l'applique aussitôt.

Le choix est écrit dans le fichier de réglages de l'application : il vaut pour tous les écrans. Un nom de modèle qui ressemble à une clé collée par erreur est refusé et signalé en rouge.

Modèle vidéo par défaut

Le modèle avec lequel naissent les nouveaux nœuds Seedance du Studio. Chaque nœud peut en changer.

Modèle de voix par défaut

Le modèle ElevenLabs des nouveaux nœuds de voix off.

Ajouter un fournisseur libre

  1. Dans Clés d'API, descendez jusqu'à Fournisseurs libres (compatibles OpenAI), puis + Ajouter un fournisseur.
  2. Choisissez un préréglage (DeepSeek, OpenRouter, Mistral, Groq, Together, xAI) ou tapez un nom et une URL en https. Collez la clé.
  3. Lire la liste demande au fournisseur ses modèles ; gardez ceux qui vous servent et le modèle par défaut, puis Enregistrer.
  4. Sur la ligne, Tester vérifie la clé, Remplacer la clé en pose une nouvelle, Supprimer demande un second clic (Confirmer la suppression) et efface la clé.

Le fournisseur devient le moteur fl:<nom> : ses modèles rejoignent toutes les listes de modèles de texte (dialogue IA du Vectorlab, rôles ci-dessus). La clé va au coffre et n'est jamais réaffichée.

Brancher plusieurs serveurs locaux

  1. Sous LLM local (Ollama), la liste Serveurs locaux commence par votre Ollama, réglé juste au-dessus.
  2. + Ajouter un serveur : choisissez un préréglage (Ollama, LM Studio, llama.cpp, vLLM) ; l'URL doit être sur ce PC ou sur votre réseau local.
  3. Lire les modèles remplit la liste, choisissez le modèle par défaut, puis Enregistrer.
  4. Tester dit si le serveur répond et combien de modèles il publie.

Chaque serveur devient le moteur local:<nom>, gratuit, dans les mêmes listes que les fournisseurs libres.

Protéger vos clés dans le coffre

  1. Ouvrez Réglages › Coffre.
  2. Choisissez un mot de passe maître (8 caractères au moins), tapez-le deux fois, puis Poser le coffre. Vos clés sont chiffrées et quittent le fichier en clair.
  3. Fermer retire les clés de la mémoire : plus rien de payant ne part. Ouvrir les rend actives avec le mot de passe.
  4. Retenir sur ce PC ouvre le coffre tout seul au lancement, pour votre session Windows ; Ne plus retenir redemande le mot de passe.

Sur chaque ligne de Clés d'API, une pastille dit où vit la clé : dans le fichier, dans le coffre, ou coffre fermé (un clic vous y mène).

Bon à savoir

Le mot de passe du coffre n'est stocké nulle part : perdu, il ne se retrouve pas. Notez-le, ou gardez une archive chiffrée.

Exporter l’archive crée un fichier .dzk qui emporte vos clés, vos plafonds et vos tarifs vers un autre PC ou votre téléphone, protégé par son propre mot de passe. Importer une archive… les reprend.

Réglages › Diagnostic montre l'état de toutes les clés d'un coup (jamais leur valeur) et les soldes des fournisseurs. Chaque ligne porte Régler, qui ouvre la rubrique où la clé se règle.
