Vous saurez enchaîner les écrans pour aller d'une idée à un résultat publié ou imprimé. Chaque parcours renvoie aux chapitres qui détaillent chaque étape ; le coût éventuel est annoncé à chaque fois avant le tir.

Une image, puis un post

  1. Dans la Bibliothèque, décrivez l'image puis Créer l'image (payant, prix affiché), ou importez la vôtre.
  2. Retouchez-la si besoin dans le Photolab : Envoyer vers… › Photolab, puis Enregistrer.
  3. Envoyer vers… › Scheduler crée un brouillon de post ; le Planificateur règle la légende, les canaux et le créneau. Rien ne part sans votre clic.

Un reel tiré de l'actualité

  1. Dans News, laissez le classement gratuit trier les articles du jour.
  2. Chaîne du jour : choisissez la forme du reel (les cartes animées sont gratuites), puis Préparer (gratuit).
  3. Relisez le script et la légende, puis Programmer le lot : le post arrive dans le Planificateur avec son reel.

Un épisode de votre roman

  1. Dans Chapitres, collez votre chapitre ; l'Atelier en tire le découpage, la bible et le storyboard.
  2. Bloquez les plans délicats sur le Plateau 3D avant de payer la moindre vidéo.
  3. Assemblez l'épisode, finissez-le dans le Montage (titres, mixage, sous-titres), puis livrez aux formats de chaque réseau.

Un jeu de cartes imprimé

  1. Dans le Card Forge, partez d'un modèle, importez vos données (CSV, Google Sheets, Notion) et réglez le format.
  2. Retouchez une face dans le Vectorlab si besoin (« Éditer cette face dans le Vectorlab »).
  3. Module 07 : choisissez le gabarit de votre imprimeur, laissez le contrôle avant vol relire le fichier, puis exportez le paquet imprimeur. La Forge 3D ajoute jetons et boîte.

Une figurine imprimée en 3D

  1. Choisissez une image bien détourée et générez le modèle dans l'onglet 3D de Game Assets (payant, prix affiché), ou préparez d'abord ses vues gratuitement.
  2. Ouvrez-le dans l'Établi : taille cible, réparer, poser, regarder les surplombs, ranger sur le plateau.
  3. Export › Impression 3D, puis Ouvrir dans le slicer : voir Imprimer ses créations.

Une campagne pour un client

  1. Créez l'espace du client et vérifiez ses canaux : Travailler pour des clients. Reliez son WhatsApp au même endroit : Parler à ses clients sur WhatsApp.
  2. Partez d'un post qui vous inspire : Scanner une page, une inspiration, un schéma. Le brouillon arrive au Planificateur sur les canaux du projet.
  3. Faites-le valider par le client, puis programmez-le ; la diffusion WhatsApp part avec lui.

Un tutoriel vidéo de l'application

  1. Filmez votre geste, habillez-le d'un skin et montez la capture : Filmer l'app et passer en direct.
  2. Planifiez le brouillon de la vidéo dans le Planificateur, et exportez le parcours pour qu'un autre le rejoue.

Des assets pour votre jeu

  1. Animez un personnage dans le Sprite Lab et exportez la feuille pour Unity, Godot ou Phaser.
  2. Fabriquez un jeu de tuiles dans le Tile Lab à partir de deux matières, peignez une carte, exportez vers Tiled, LDtk ou Godot.
