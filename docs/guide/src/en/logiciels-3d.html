You will tell Deepotus where Blender and Godot are installed, check their version, and know what each one receives from the app. Five minutes; free: nothing is sent outside your PC.

Before you start

You need Blender 4.2 or later (blender.org) and Godot 4 or later (godotengine.org, or Steam). Godot has no installer: it is an .exe file you put wherever you like. To drop assets into it, also keep a Godot project at hand: its folder contains the project.godot file.

Set up Blender

  1. Open Settings › 3D engines and software.
  2. On the Blender card, click Detect. Deepotus looks in Program Files, then in the PATH, and lists what it finds, newest version first. It saves nothing.
  3. Click Use next to the Blender you want, then Save. Field left empty: Deepotus itself picks the newest Blender it finds.
  4. Click Test: the reply gives the version, read without opening a window. A version older than 4.2 is refused, and the reply says so.

Set up Godot

  1. On the Godot card, click Detect; otherwise, paste the full path to the .exe file into Executable.
  2. In Project folder, paste the folder that contains project.godot.
  3. Click Save next to each field: it applies right away.
  4. Click Test: the reply gives the Godot version and the project name. A folder without project.godot is refused, and the reply says so.

What each one receives

Blender

Shot passes, 3D Studio FBX export and FBX import. From the Workbench, it opens the prepared part (see Prepare a part before slicing).

Godot

SpriteFrames (.tres), TileSets, .tscn scenes with hitboxes and .glb models, dropped into the project's deepotus/ folder. See Animate sprites and Paint tiled levels.

Good to know

Unreal Engine and Unity will come to this same page. Until then, their paths (UNREAL_PATH, UNITY_PATH and their project folders) are still set in the .env file.

Detect only suggests: until you click Save, the previous setting stays in place.
