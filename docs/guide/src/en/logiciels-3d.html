You will tell Deepotus where Blender, Godot, Unreal Engine and Unity are installed, check their version, and know what each one receives from the app. Five minutes per program; free: nothing is sent outside your PC.

Before you start

Install only what you use: Blender 4.2 or later, Godot 4, Unreal Engine 5 (through the Epic launcher) or Unity (through Unity Hub). For game engines, keep a project at hand: Deepotus drops its assets into a subfolder of its own.

Set up a program

  1. Open Settings › 3D engines and software: one card per program.
  2. Click Detect. Deepotus looks in the usual places and lists what it finds, without saving anything.
  3. Click Use next to the right executable, then Save. Nothing found: paste the full path to the .exe file yourself.
  4. For a game engine, also paste the project folder and click Save next to it.
  5. Click Test: the reply gives the version and, where relevant, the project name. Nothing opens on screen.

Program by program

Blender

Shot passes, FBX export and import, Workbench « Open in Blender ». Empty field: Deepotus takes the newest Blender in Program Files.

Blender MCP

The bridge that lets the Director agent read the scene open in Blender. Test starts mcp-for-blender and says whether Blender answers, changing nothing.

Godot

SpriteFrames, TileSets, .tscn scenes and .glb models, dropped into deepotus/. The project folder contains project.godot.

Unreal Engine

.glb models, T_… textures and Paper2D sprites, dropped into Content/Deepotus. The version is read from the installed engine; the project folder contains the .uproject.

Unity

.glb models, MaskMaps and sprite sheets, dropped into Assets/Deepotus. Without the glTFast package in the project, .glb files stay inert: Test points it out.

To go further: Prepare a part before slicing, Animate sprites, Paint tiled levels.

Good to know

Unity only gives its version for an editor installed by Unity Hub: elsewhere, Test says so rather than starting Unity to read it.

Detect only suggests: until you click Save, the previous setting stays in place.
