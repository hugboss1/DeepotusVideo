You will know how to find a proven method for what you want to do, follow it step by step, and discuss it with the specialist agent behind it. The screen and the cards are free; each message to an agent is paid, estimated before sending.

Find a method

  1. Open Methods in the left bar, under the Library: 94 illustrated recipes, most useful first.
  2. Type a few words in Search a method… (“grading”, “sprite”, “ad”): the search reads titles, summaries, steps and examples, in English as in French.
  3. Narrow down with the Family, Agent and Screen filters; each choice shows how many methods it keeps. Clear filters goes back to the whole gallery.

Follow a card

  1. Click a card: it opens with its Steps, Quality checks and Pitfalls to avoid, the app screens where it is done and the models it mentions.
  2. Follow the steps in the screens shown; the checks tell you how to know the result is right.
  3. The Example requests copy in one click, to reuse them as they are with the agent.
  4. All methods goes back to the gallery, with the same filters.

Talk to the specialist agent

Each card is carried by a specialist agent: the Editor, the Director, the Retoucher, Product variations, the Casting director, the Ad maker, the 2D game artist, the 3D game artist or the Picture-book editor. It knows its methods, measures your files and makes free local moves (cutting to the music, burning a title, comparing two versions, checking a format).

  1. In the card, “Talk to the …” opens the conversation on the side. An Anthropic key must be set in Settings › API keys.
  2. Describe what you want to do, with your file paths, or click an example to fill the field.
  3. Estimate the cost gives the maximum price of the message, without spending anything. The button then becomes “Send (≈ $x)”: only that click spends.
  4. The answer shows the tools the agent called and what the message cost.

Go further

The screen pill

On Edit, Quick, Studio, Chapters, Sound & VFX and the other screens that have methods, the Methods pill, bottom right, opens that screen's methods.

The Editor's edit chain

The Editor proposes a video edit step, one thing changed, as a “Launch (≈ $x)” card. The click launches it; the drift measured against the previous version tells whether camera and timing held.

The Referee

Every agent can compare the outputs of several models fairly: same reference, one output each, none left out, ranked by score, then cost, then time.

Good to know

A message is counted under its agent's category (montage for the Editor, chapitres for the Director…) and stops before going over the accepted amount. The agent never starts a paid generation: it proposes, you launch.

The methods are inspired by Scenario's public explorations, rewritten for the app: each card keeps a link to its source.
