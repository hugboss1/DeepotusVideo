You will be able to retouch pixels and make pixel art in Vectorlab, export your drawings in the right format, build a map from real data and turn a drawing into parts to 3D-print. Everything is free and computed on your PC.

The Pixel persona

  1. Click the Pixel pill (or View › Pixel Persona). The same document keeps its layers; tools and panels change. From the Game Assets hub, the Pixel card opens this persona directly.
  2. To retouch a placed image, pick it then Pixel › Edit pixels.
  3. Select pixels: rectangle (M), lasso (L), magic wand (W) or by colour; the Pixel menu grows, contracts or inverts them (Ctrl+I).
  4. Paint: brush (B) and eraser (E) with radius, hardness and round or square shape, paint bucket (G) contiguous or global, clone stamp (C), blur, dodge and burn. Right-click = secondary colour, X swaps them, Alt+click picks.

Pixel › Adjustments and filters… gives levels, curves, hue and saturation, black and white, threshold and blur. Every retouch undoes with Ctrl+Z, like the rest of the document. The Histogram tab shows the four channels of the edited image.

Make pixel art

The Pixel-art panel sets tile size, symmetry, palette (the same as Sprite Lab and Tile Lab), quantization and the pixel grid. The pixel pencil (K) draws without double pixels in diagonals; Shift+click draws a straight segment from the last point.

Trace a reference

Set as reference fades and locks an image with its grid; a pixel layer sits on top to draw cell by cell, the eyedropper takes a cell's exact, average or dominant colour.

Pixelate

Pixelate turns an image or a vector selection into big pixels. Rasterize adds palette and dithering (ordered or Floyd-Steinberg).

Tiles and seams

The 3×3 preview scores a tile's seams; the 2:1 iso tile limits painting to the diamond, with symmetry along its edges.

Animation

The timeline shows frames: play (Enter), loop, FPS, red (previous) and blue (next) onion skin. Export as a PNG + JSON sheet or a strip.

Finishing

Dark outline sets the drawing off the background, Sharpen boosts contrast; PNG export scales from ×1 to ×16 without blur.

To the other labs

Pixel › Pixel art to Tilelab… sends the drawing to Tile Lab; the Pixel-art panel also sends it to Sprite Lab.

Export

  1. Open the Export tab (File › Export… or Window › Export), shared by both personas.
  2. Choose what goes out: the whole document, each artboard, each visible layer, each selected object, or the slices drawn with the Slice tool.
  3. Choose the format (PNG, JPEG, WebP, SVG, PDF, DXF) and one or more resolutions (@1x, @2x…). File names build themselves; a batch export outputs every slice, resolution and format at once.

Vector PDF

By default: text as outlines, page at physical size, vector gradients and patterns, crop marks and bleed for the printer. A message says what had to be rasterized and why.

DXF for cutting

In millimetres, text as glyph outlines, symbols and groups included.

Quick exports

File › Export SVG (embedded images), Export PNG 2×, and Send to Bible… for a chapter.

A real map

Document › Real map… opens the Map panel: no key, no cost, it lays a shaded relief, draws contour lines as vector paths at the chosen interval, adds an OpenStreetMap background with its attribution, and slices the map into hexagonal tiles coloured by altitude. File › Import GPX… places a track at true scale, keeps its altitude (profile, length, climbs) and can turn it into a raised ribbon.

Print in 3D

  1. File › 3D Print… (or Text › 3D Logo…). Choose the mode: layers (one height per layer), board tiles with base, logo (bevel, hollowing with a minimum wall), map relief, or pixel art (one height per colour).
  2. Set heights and options, then 3D preview: the model turns in the viewer, each part in its colour, with dimensions, triangles and volume. A model wider than the bed is flagged.
  3. One STL for a single part, or Batch per tile / slab: one STL per part, a coloured plateau.3mf and nomenclature.csv. Open the slicer hands over to your printing software.

In relief mode, numbered slabs get sockets under the base and separate keys (0.2 mm clearance) to fit together. Side draft tilts a logo's edges for demoulding.

Good to know

A text must be converted to curves to be printed: the dialog says so and skips it otherwise. To go further with a 3D model, see the Workbench and 3D printing.
