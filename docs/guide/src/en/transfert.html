You will take all your work to another computer, check that nothing got damaged on the way, and get your keys back there. Fifteen minutes, free; the app must be installed on both machines.

What travels

The transfer takes everything the app created: the Library and the origin of every file, renders, the bible, communication plans, vector documents, card series and 3D models. Your API keys never go into the package.

Export from the old PC

  1. Open Settings › Machine transfer: the number of files and the size to take are shown.
  2. Click Export…, then pick the destination: a drive, a USB stick, or a path.
  3. Tick the extras if you want them: Logs and Discards — dated trash folders. They are unchecked by default, with their size.
  4. Start export: a dated folder is written at the destination, each file with its checksum. Do not close the app while it writes.
  5. Click Check integrity: every written file is read back and compared with its checksum.

Import on the new PC

  1. Install the app, then open Settings › Machine transfer and click Import….
  2. Give the package folder, then Check: the app reads the package without writing anything and tells where it comes from (date, machine, version).
  3. Start import. Import adds: nothing this PC already has is overwritten. A damaged file is left out and named.

Take your keys too

  1. On the old PC: Settings › Vault › Export archive, with a separate password.
  2. On the new PC: Import an archive… and that password. Your keys, caps and rates come back.

Good to know

Paths from the old machine are rewritten for the new one: your projects find their files without any setting.

Stopping an export leaves an incomplete package. If it happens, run the export again, then Check integrity before importing.
