You will be able to recognise the most common messages and know what to do. Always start with Settings › Diagnostics: version, disk space, latest alerts, key status (never their value) and provider balances, at a glance.

Symptoms and fixes

SymptomWhat to do
A button says a key is missing, or a provider pill is red at the top right.Add or fix the key in Settings, keys section (see Connect your keys). It works straight away, no restart.
A generation is refused: cap reached.The window says which cap blocks and offers to adjust it. See Keep spending under control.
The HeyGen avatar list takes a while to appear the first time.Normal on the very first load: the list is long. It is then kept on disk and shows instantly.
An ElevenLabs voice returns a plan error.On ElevenLabs' free plan, only “premade” voices work through the API. Pick one, or move to a paid plan.
Certificate error (CERTIFICATE_VERIFY_FAILED).An antivirus inspects HTTPS. The app uses Windows' certificates and handles it on its own; otherwise, turn off the antivirus's HTTPS inspection.
“Port 8765 already in use”.The app is already running: open http://deepotus.localhost:8765.
After a restart, my keys or Library seem “gone”.Nothing is lost: everything lives in %LOCALAPPDATA%\DeepotusVideoGenData. Start the app again from its Desktop icon.
Photolab returns to its welcome screen with an engine message.The retouching engine was restarted; unsaved documents are lost. Save often (see Photolab).
A 3D file is refused at print export.Go through the Workbench: set a target size and repair in one click before exporting.
I deleted an image by mistake.It is in the Library Trash: Restore.

Where are my files?

In %LOCALAPPDATA%\DeepotusVideoGenData\assets: images for images, outputs\final for rendered videos, outputs\uploads for your uploads, audio for sounds, print3d for print exports. To take everything to another PC, see Move to another computer.

Good to know

An app message always says what blocks and how to fix it. If a button is greyed out, hover it: its tooltip says why.
