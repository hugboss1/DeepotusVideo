You will be able to record a series of Photolab gestures to replay it in one click, apply it to a whole batch of images, and output a document as more than a single image: one file per layer, one file per data set. Free, computed on your PC.

Record an action

  1. Open the Actions tab, in the Layers group, or Window › Actions.
  2. Click New action at the bottom of the panel: give it a name, an action set and a colour if you like, then Begin recording.
  3. Work as usual: every adjustment, filter or command applied to the document becomes a step under the action.
  4. Stop ends the recording. To replay, pick the action then Play selection: it applies to the open document, one history step per gesture.

A tick switches a step off without erasing it; the box next to it opens its dialog during playback, to change a value on the way. The panel menu inserts a stop with a message, a conditional (“if the document is landscape, play this action”) or a menu command, and Edit Step… redoes a step with new values.

Process a batch of images

  1. File › Automate › Batch…, or the same item in the Actions panel menu.
  2. Pick the action, then the Library images to process (500 at most), and Run.
  3. Each image is opened on its own, processed, then dropped into the Library, linked to its original image. Your open document is left alone.

Export differently

Layers to files

File › Export › Layers to Files… outputs each layer, or only the visible ones, as PNG or JPG into the Library.

Export as

The export dialog keeps your settings as named presets and warns when a format loses something: flattened layers, lossy compression, resolution dropped.

Variables and data sets

Image › Variables › Define… makes a layer variable (shown or not, text replaced). A data set gives each variable a value; Image › Apply Data Set… shows it.

One file per set

File › Import › Variable Data Sets… reads a CSV table; File › Export › Data Sets as Files… outputs one image per set, for example one card per name.

Good to know

Your actions stay from one session to the next. Save Actions… and Load Actions…, in the panel menu, exchange .atn action files through the Library: a step with no equivalent arrives switched off.

Scripts and droplets are not supported. An action only plays commands Photolab can do: before each playback its steps are checked, and a refused step stops it with a message.
