## 0. Les quatre exigences, mesurées dans le code (état au 22/09)

| Exigence | État | Ce qui existe, exactement | Ce qui manque |
|---|---|---|---|
| **Récupérer dans Montage les rendus de Studio** | partiel, par effet de bord | (A) `GET /api/montage/project` sans sauvegarde pose les **4** derniers jobs `done` à artefact vidéo (`.mp4 .mov .webm .mkv .m4v .avi`, `.limit(60)` de candidats, `montage_service.py:1352-1432`) sur V1 avec un jumeau A1 « · son du plan » ; (B) le sélecteur `openPicker` (bouton **lier** du groupe BIBLIOTHÈQUE, « + » d'une piste vidéo) — panneau **« Ajouter sur la piste V1 »**, sections « Images (Bibliothèque) » / « Rendus vidéo » / « Sons (Bibliothèque) », **12** rendus au plus (`.slice(0,12)` sur les 50 derniers jobs), chips cliquables et glissables ; (C) Bibliothèque → onglet Renders → vignette → **« Envoyer vers… » → « 🎞 Montage — clip vidéo »** (`patch_bundle_libsend.py:201`), qui pose sur **`v2`** en dur (`:253-259`) ; (D) « Remplacer la source… » (`GET /newer`, rapprochement par titre) | le mot **Studio n'existe nulle part** (aucun filtre par provenance : `seedance / heygen / composition / template / news` sont indistincts) ; deux règles « est-ce une vidéo » différentes (Bibliothèque : par `provider`, picker : par extension) ; (C) pose sur `v2` même quand la piste n'existe pas (sauvegarde du 04/09 sans v2 → clip **invisible** mais rendu) ; pas de retour de Studio vers le Montage |
| **Récupérer les vidéos de Chapitres** | partiel, par effet de bord | Chapitres (`id:"episodes"`, `POST /api/episodes/render`, `provider="episode"`, `outputs/final/<job>.mp4`, 9:16) : le job passe (A), (B) et (C) puisqu'il est `done` et `.mp4` ; chip de provenance **« Episode »** dans la Bibliothèque | **aucun bouton dans Chapitres** vers le Montage (`__dzSendNav("montage")` n'existe que dans la Bibliothèque) ; arrivée sur `v2` = incrustation **muette** (le son gravé n'est lu que par le jumeau A1, créé seulement par (A)) ; les **scènes** de l'épisode ne sont pas transmises (un `.mp4` plat) |

## 3. Ce que cette conception ne fait pas

- Pas de multi-timeline dans un projet, pas de bins/Smart Bins, pas de Cloud/Network : un projet reste une timeline, la « Bibliothèque » reste l'unique pool.
- Pas d'upload direct vers YouTube/TikTok depuis le Montage : la publication reste le Scheduler (E-4 lui donne un vrai bouton et un vrai formulaire).
- Pas de refonte des CSS `son-vfx-montage.css` (intouchable) : toutes les règles neuves vont dans `montage.css` ; les vues E-7 sont des états d'affichage, pas des écrans neufs.
- Aucun plan ni code avant la validation de ce tableau.
