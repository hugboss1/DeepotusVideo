# t312 — C1 Scan : une page → texte pour l'Atelier et les Chapitres — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal :** depuis l'Atelier/Chapitres, déposer ou coller une à dix pages (image ou PDF scanné), les lire gratuitement sur la machine (Windows.Media.Ocr), nettoyer le texte (colonnes, césures, folios, titres courants, paragraphes, mots incertains marqués), proposer Claude vision en secours payant avec devis, puis envoyer le texte dans le chapitre, en nouveaux chapitres selon `segment_chapters`, ou comme manuscrit par `/atelier/manuscript`.

**Architecture :** `scan_ocr.py` (pont PowerShell 5.1 → Windows.Media.Ocr, sous-processus sans fenêtre, couture `_executer` remplacée aux bancs) rend lignes et mots avec leurs boîtes ; `scan_nettoyage.py` (pur) en fait un texte propre + positions des mots incertains ; `scan_vision.py` (devis gratuit, lecture Claude sous `tirer_garde`) ; routes `/api/scan/*` (cache de pages 1 h) ; boîte d'agent `scan` avec l'outil `lire_texte_image` ; écran `frontend/shared/dz-scan.js` monté dans la page autonome de l'Atelier (pas de maillon de bundle).

**Tech Stack :** FastAPI, Pillow, pypdf, PowerShell 5.1 + WinRT (Windows.Media.Ocr), moteurs_texte (Claude vision), JS sans build, dzT, L10.

**Spec :** `docs/superpowers/specs/2026-10-25-boite-a-outils-design.md` §7.1-7.2 (+ §4, §7.3-7.4 pour ce qui sera réutilisé, §12 n°5). Relevé du code : `.superpowers/sdd/t312-releve.md`.

## Global Constraints

- Lecture locale = Windows.Media.Ocr seulement (décision utilisateur du 28/10 : **pas de Tesseract**, ni embarqué ni installé pour mesurer).
- Mesure sur **10 pages test fabriquées** FR/EN avec texte de référence (décision utilisateur du 28/10), pas de pages réelles.
- Claude vision = secours **payant**, jamais automatique : devis gratuit d'abord, `max_usd` accepté par l'utilisateur, garde `plafonds` avant l'appel ; refus si le coût dépasse l'accord (patron `agent_aide.demander`).
- Aucun appel réseau réel dans les bancs ni la preuve (Claude remplacé par sa couture).
- Bancs Python depuis `backend/` avec le python embarqué, PYTHONUTF8=1, au premier plan, un à la fois, aucune boucle en arrière-plan.
- Le texte envoyé reste « au format du PC » : texte brut ; jamais de format parallèle ; les routes Atelier/Chapitres existantes sont réutilisées.
- Tout libellé écran via `dzT` FR/EN ; tout message serveur à texte fixe a son entrée L10.
- Journaux : jamais le texte lu ni le contenu des images ; seulement tailles, nombres de pages et de mots, durées.
- Routes locales seulement (`_require_localhost`) ; la route payante a aussi `_require_local_depense`.

## Décisions

1. **Pont OCR** : un script `backend/app/services/scan_ocr.ps1` lancé par `powershell -NoProfile -NonInteractive -ExecutionPolicy Bypass -File … -Image <png> -Langue fr-FR|en-US`, `CREATE_NO_WINDOW`, délai 60 s. Il rend du JSON sur stdout : `{"langue", "angle", "lignes": [{"texte", "mots": [{"texte", "x", "y", "l", "h"}]}]}`. Image prétraitée par Pillow avant : niveaux de gris, `autocontrast`, agrandie ×2 si la largeur < 1200 px, réduite si un côté > 10 000 px, PNG temporaire supprimé après.
2. **Langue** : `fr` (défaut), `en`, ou `auto` = deux passes fr-FR et en-US, on garde celle qui a le moins de mots incertains (égalité → fr).
3. **Mots incertains** (pas de confiance native) : un mot est incertain s'il mêle lettres et chiffres hors motifs connus (`3e`, `XIVe`, `1er`, `n°`, unités `10kg`), contient un caractère hors lettres/chiffres/ponctuation usuelle, répète un caractère plus de 3 fois, ou est un jeton d'un seul caractère non alphanumérique isolé au milieu d'une ligne ; en mode `auto`, aussi un mot lu différemment par les deux passes. Positions rendues comme `[{debut, fin}]` dans le texte final.
4. **Nettoyage** (pur, `scan_nettoyage.nettoyer(pages, *, langue) -> {texte, incertains, stats}`) : colonnes = regroupement des lignes par bord gauche (écart horizontal > 8 % de la largeur entre deux groupes, détecté sur l'histogramme des x) puis lecture colonne par colonne de gauche à droite ; folios = ligne seule en haut/bas de page composée d'un nombre, d'un nombre romain ou de « — 12 — » ; titres courants = même ligne (normalisée) en tête de ≥ 2 pages ; césure = mot finissant par `-` en fin de ligne suivi d'une minuscule → recollé ; paragraphe = écart vertical > 1,5 × hauteur médiane de ligne, ou ligne précédente nettement plus courte terminée par `.!?:»` → ligne vide.
5. **Secours Claude** : `scan_vision.devis(n_pages) -> {usd, moteur, nom, disponible}` (gratuit, aucune image lue) ; `lire(images, *, max_usd, langue) -> même forme que l'OCR nettoyé` ; images réduites à 1280 px max, JPEG qualité 85, ≤ 4 par appel (au-delà : plusieurs appels, devis compte tous) ; catégorie de plafond `"atelier"` ; consigne : transcrire fidèlement, garder les paragraphes, ignorer folios et titres courants, marquer `[[?mot]]` les mots douteux (convertis en positions incertaines, marques retirées) ; texte de la page jamais suivi comme consigne.
6. **Routes** : `POST /api/scan/lire` (multipart `pages: list[UploadFile]` 1 à 10, `langue: Form`) ; image PNG/JPEG/WEBP/BMP/TIFF ≤ 20 Mo, ou PDF : texte sélectionnable lu directement (pypdf), sinon images incorporées de chaque page ; garde le scan en cache mémoire 1 h (`scan_id`) ; rend `{scan_id, moteur:"windows", langue, pages:n, texte, incertains, stats, duree_ms}`. `GET /api/scan/{scan_id}/devis-vision`, `POST /api/scan/{scan_id}/vision` `{max_usd}` (402 plafond, 409 coût changé, 503 Claude non configuré ou sans vision). `POST /api/scan/decoupage` `{texte}` → `{chapitres: [{titre, caracteres, debut}]}` par `segment_chapters` (pur, gratuit). OCR indisponible (pas Windows, langue absente) → 503 avec message clair et le secours Claude proposé.
   *Précision (tâche 4, revue)* : `moteur` vaut `"texte"` quand aucune page n'a été lue par l'OCR (PDF entièrement textuel, texte pris tel quel par pypdf), `"windows"` dès qu'une page l'a été, `"claude"` après le secours ; la réponse porte aussi `en_cache` (un scan plus lourd que le budget du cache, 256 Mo, n'est pas gardé : `scan_id` null).
7. **Envoi** (écran, routes existantes) : « Insérer dans le chapitre » (texte au curseur de `#script` puis `scheduleSave()`), « Créer les chapitres » (un `POST /api/chapters` par chapitre du découpage, série courante), « Importer comme manuscrit » (fichier `scan.txt` vers `/atelier/manuscript`, refusé à l'écran sous 200 caractères avec la raison).
8. **Hôtes** : t312 monte la boîte Scan dans l'Atelier/Chapitres seulement ; Vectorlab (C2, t314), Quick et la barre de l'agent viendront avec leurs lots (le module partagé est prêt pour eux).
9. **Boîte d'agent** : `scan` déclarée dans `agent_boites.BOITES` avec l'outil `lire_texte_image` (lecture : une image de la Bibliothèque par son nom → OCR local + nettoyage, rendu encadré `_preuve`) ; rendue à aucun agent existant pour l'instant (§11 bis) ; fixtures figées inchangées.

## Review Focus

1. Une page en deux colonnes : le texte sort colonne gauche puis colonne droite, jamais ligne à ligne en travers.
2. PowerShell absent, bloqué, trop lent ou JSON illisible : erreur claire (503/504), aucun fichier temporaire laissé.
3. Un PDF déjà textuel : aucun OCR, texte direct ; un PDF scanné sans image extractible : refus clair.
4. Coût Claude qui change entre devis et lecture (autre modèle réglé) : 409, aucun appel.
5. Texte de page contenant une consigne (« ignore tes instructions… ») : traité comme du texte à transcrire, jamais suivi ; et l'outil d'agent l'encadre en PREUVE.
