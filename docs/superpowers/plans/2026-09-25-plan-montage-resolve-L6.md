**Mesures ffmpeg** (9.0.1 = 8.1.1 à 0,01 dB, aide des filtres identique) :
- **EQ** : `equalizer=f=F:t=q:w=Q:g=G` exact (±12,00 dB à 60/250/1k/4k/10k, retard 0, identité à g=0) ; `lowshelf`/`highshelf` présents ; `anequalizer` = plateau (écarté pour l'EQ), `firequalizer` = 480 échantillons de retard et +7,3 au lieu de +12 à 60 Hz (PROSCRIT). `f=0`/`w=0`/f > Nyquist passent sans effet ; `g` hors bornes ou `f<0` FONT ÉCHOUER le rendu → borner côté serveur. Sur une source s16, un `equalizer` en dernier maillon écrête : `aformat=sample_fmts=fltp` en tête. Coût 6 biquads ≈ 0,24 s pour 60 s stéréo.
- **Pan** : `stereotools balance_out` = balance LINÉAIRE (−6,02 dB à ±0,5) ; tout upmix mono → stéréo implicite coûte −3,01 dB/canal ; loi à puissance constante mesurée : θ = (p+1)·π/4, gL = min(1, √2·cos θ), gR = min(1, √2·sin θ) → 0 dB au centre, −5,33 dB à ±0,5, identité exacte à 0, canal éteint à ±1 (comme `balance_out=±1`).
- **De-hum** : `bandreject=f=k·F:width_type=q:w=10:m=<dosage>` en cascade : −33 à −82 dB au cran exact, −19 dB à 0,3 Hz de dérive, voix −0,2 dB (50 Hz) ; `m=0.5` ≈ −6 dB (dosage linéaire en amplitude) ; Q ≥ 30 ne tient plus la dérive ; `anequalizer` exige de déclarer chaque canal (un canal non déclaré passe intact) → écarté ; 4 harmoniques par défaut (à 60 Hz la 5ᵉ = 300 Hz, dans la voix). `afftdn`/`anlmdn`/`highpass` n'enlèvent RIEN d'un ronflement stable. **`anlmdn` PLANTE sur 9.0.1** (code 139/127, ≈ 85 % des lancements) → PROSCRIT.
- **Débruitage** : `afftdn` options identiques sur les deux binaires ; hors bornes = échec (pas de bornage) ; **`nf` est le verrou** : défaut `nf=-50` face à un bruit à −40 dBFS = −1 dB seulement ; règle validée `nf = clamp(RMS(plage de bruit) + 10, −80, −20)` (RMS par `astats=measure_overall=RMS_level:measure_perchannel=none` ; son « Noise floor dB » n'est PAS utilisable) ; apprentissage `asendcmd=c='0.0 afftdn sn start;L−0,05 afftdn sn stop'` (valeurs `start|begin|1`, `stop|end|2`) : bruit coloré −7,6 dB (nf seul) → **−24,0 dB (préfixe appris, nr=24)**, voix −0,33 dB au pire à −40 dBFS ; `tn=1` CASSE l'apprentissage ; `gs=10` abîme la voix.
