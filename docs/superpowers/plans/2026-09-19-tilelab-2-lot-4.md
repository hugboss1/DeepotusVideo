## Décisions d'implémentation

- **Palettes** : `PALETTES = [{ id, nom, couleurs: [hex maj], backend: bool }]`.
  Spritelab et Tilelab remplissent leur `<select id="pixPalette">` depuis
  la liste (option « Adaptative » en tête, seules les `backend: true`
  sont proposées puisque la pixelisation s'y fait) ; le Vectorlab propose
  toutes les palettes dans « Préréglage » et pose `doc.pixelart.palette`.
  Un banc vérifie que les cinq identifiants backend et leurs hex sont
  EXACTEMENT ceux de `pixel_ops.py` (le banc lit le fichier Python en
  texte) — une dérive casse le banc.
- **Détection des tuiles** : composantes connexes 4-connexes de l'alpha
  (> 0), bbox par composante, filtre `min` (côté ≥ 2 px), tri par `y` puis
  `x` ; deux composantes dont les bbox se chevauchent sont fusionnées
  (un sprite en deux morceaux). `taille_commune` = la médiane des
  largeurs et des hauteurs (arrondie au pair le plus proche pour l'iso).
- **Grille de placement** : `{ type: "carree" | "iso", cols, rows, cell_w,
  cell_h }` ; placement = `{ c, r, tuile }` ; rendu : carré → `x = c·w, y
  = r·h` ; iso → `x = (c − r)·w/2 + (rows − 1)·w/2, y = (c + r)·h/2` (le
  losange de chaque tuile posé à ces coordonnées, la tuile entière est
  dessinée — c'est elle qui porte son losange). Le canvas de la grille se
  redessine à chaque changement ; l'utilisateur choisit une tuile dans la
  liste puis clique des cellules (clic droit = retirer).
- **Seam ×9** : double-clic sur une tuile de la liste → `raccord_3x3` (carré)
  ou `pavage_iso` (iso) de `mod-pixelart` (import `/vectorlab/js/`), avec
  le score, dans un aperçu.
- **Exports** : feuille alignée = chaque tuile centrée dans une cellule
  uniforme `taille_commune (+ pad)` sur `cols` colonnes, PNG + JSON `{
  cellule, cols, tuiles: [{nom, x, y, w, h, source: {x, y, w, h}}] }` ;
  tileset peint = le canvas de placement en PNG + JSON des placements ;
  tuiles séparées = un PNG par tuile (téléchargements successifs, nommés
  `<base>_tuile_<i>.png`, plafond 64 dit) ; « Save to Library » dépose la
  feuille alignée (`tiles_feuille_<ts>.png`).
