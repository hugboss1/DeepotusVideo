## Décisions d'implémentation

- **Contours vrais** : `contours_de_masque(masque, w, h)` collecte, pour
  chaque pixel du masque, ses arêtes de bord (voisin hors masque ou hors
  image) orientées pour tourner CCW autour de la matière (bas : →, droite
  : ↑, haut : ←, gauche : ↓ dans le repère y-bas… puis on retourne y),
  puis chaîne les arêtes par sommet (au choix du sommet à quatre arêtes :
  tourner à droite pour ne pas fusionner deux régions en contact
  diagonal). Aire signée : > 0 = extérieur, < 0 = trou ; un trou est
  rattaché à l'extérieur qui contient son premier sommet (test
  pair-impair). Résultat : multipolygone `[[ext, trou, …], …]` fermé,
  directement extrudable (`extruder` gère les trous par ponts). Le banc
  mesure : un carré plein 2 × 2 → 1 anneau de 4 sommets (les colinéaires
  sont éliminés), un anneau (donut 3 × 3 sans centre) → 1 extérieur + 1
  trou, volume exact, triangles ≤ ceux des rectangles.
- **Plusieurs modèles** : `doc.pixelart.paires = [{ modele, cellule, calque
  | null }]` ; `modele` / `calque` restent la paire ACTIVE (compatibilité :
  un document sans `paires` mais avec `modele` = une paire). Désigner un
  nouveau modèle AJOUTE une paire et l'active ; un select « Modèle » dans
  le panneau bascule la paire active ; Retirer retire la paire active.
- **Rotation** : la grille d'aperçu se dessine en coordonnées DOCUMENT
  dans `<g transform="translate(tx ty) scale(zoom)"><g transform="${m.transform}">`
  — la même chaîne que le rendu, donc la grille tourne avec l'image.
- **Palettes backend** : `gray16` et `handheld4` ajoutés à
  `pixel_ops.PALETTES` (mêmes hex que `palettes.js`), `backend: true` côté
  JS, le banc JS vérifie désormais les sept ; pytest `test_palettes_presets`
  passe à sept. Relance du backend installé par l'utilisateur.
- **Réordonnancement** : `tuiles_deplacer(tuiles, i, delta)` (pur,
  renomme `tuile_<k>` dans l'ordre) ; ◀ ▶ sur la vignette sélectionnée ;
  les placements suivent (index remappés).
- **Zip** : `zip_store([{ nom, data }])` (pur, méthode 0, CRC-32 table,
  dates fixes) → `Uint8Array` ; « ⬇ Tuiles séparées (zip) » télécharge
  `<base>_tuiles.zip` ; le banc vérifie signatures, nombre d'entrées, CRC
  et offsets ; la preuve dézippe avec python.
- **Playground Spritelab** : fonds « Ciel », « Extérieur », « Donjon », «
  Cave » en dégradés CSS (aucun fichier), **Invert L/R** (`scaleX(-1)` sur
  le canvas), déplacement **WASD / flèches** (translation du canvas dans la
  scène, bornée), vitesse 0,5 · 1 · 2 (multiplie le FPS effectif), le tout
  aussi pour le lecteur de la Feuille (même `player`).
- **Retouche** : `contour_sombre(img, couleur, epaisseur)` = dilatation
  4-connexe de l'alpha de `epaisseur` px, les pixels nouveaux prennent
  `couleur` (alpha 255) ; `accentuer(img, force)` = masque flou (img + force
  × (img − flou 1 px)), alpha conservé ; `agrandir(img, k)` = plus proche
  voisin ×k ; boutons dans Ajustements, « Exporter PNG ×N » (1–16) dans le
  panneau Pixel (téléchargement, nom `vector_<doc>_<href>_x<N>.png`).

```js
{

}
```
