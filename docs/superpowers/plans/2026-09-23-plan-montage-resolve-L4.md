### Décisions prises sur les démentis

1. **fps en dur et pas de 4K** → les presets ne fixent PAS le ratio (il reste celui du projet) mais la **classe de taille** (`side` = grand côté : 720 / 1080 / 2160) : `_deliver_dims(ratio, side)` = `_CANVAS[ratio]` mis à l'échelle sur le grand côté, arrondi pair ; `fps` = payload (`24|25|30|60`) sinon preset sinon 30 ; l'aperçu reste 480p/x264/30 (inchangé).
2. **Encodeur « si présent »** → `_encoder_ok(name)` sonde par un encodage réel d'une image (`-f lavfi -i color=…:d=0.1 -frames:v 1 -c:v name -f null -`), mise en cache par processus ; le preset `hevc` prend `hevc_nvenc` si OK sinon `libx265`.
3. **GIF** → dernier maillon vidéo `split[g0][g1];[g0]palettegen[pal];[g1][pal]paletteuse[outv]` à 12 i/s, côté 480, pas d'audio ; **audio seul** → `-vn`, `-map` audio seul, extensions `.m4a/.mp3/.wav`.
4. **ProRes** → `prores_ks -profile:v 2`, `pix_fmt yuv422p10le`, `.mov`, audio `pcm_s16le` ; le maillon `format=yuv420p` devient `format={pix_fmt}`.
5. **Presets maison** = `{id, label, base, fps?, crf?}` dans `deliver_presets.json` (data dir, `_write_json_atomic`, verrou `_ecrit`), `GET/PUT /api/montage/deliver-presets` ; un preset maison n'est qu'un base + surcharges (pas de codec libre).
6. **Loudness** : `loudness` ∈ {−14, −16, −23} ou absent ; **passe 1** = le graphe audio de `/measure` avec `loudnorm=I=T:TP=-1.5:LRA=11:print_format=json` (lecture du JSON en fin de stderr), **passe 2** = `[outa]loudnorm=I=T:TP=-1.5:LRA=11:measured_I=…:measured_TP=…:measured_LRA=…:measured_thresh=…:offset=…:linear=true:print_format=summary,aresample=48000[outn]` mappé à la place de `[outa]` ; cas `anullsrc` (aucun audio) → pas de loudnorm ; preview → pas de loudnorm. Pastille = pure `dzmLoudPastille(i, cible)` : vert |Δ| ≤ 1 dB, jaune ≤ 3, rouge sinon, gris sans cible.
7. **File** : `queue:true` dans le payload → le job naît `status="queued"`, `progress=0`, et est poussé dans `_RENDER_QUEUE` (asyncio.Queue) servie par UN worker (`_render_worker`, créé au premier usage, `asyncio.create_task`) qui exécute `_run` en série ; sans `queue`, comportement historique (immédiat). Le client n'affecte PAS `job` pour un rendu en file (pas de poll, note « Ajouté à la file — n en attente »), le badge de statut de la vue Livraison (queued/en cours/terminé/échec) suit `GET /api/jobs`.
8. **Plage** : payload `range:[a,b]` (secondes) seulement si la case « Rendre la plage I/O » est cochée ET `proj.range` valide ; backend : `-ss a` avant `-t`, `-t = min(b,total)-a`, `range` ignoré si invalide (a<0, b≤a, a≥total) — note 400 « plage invalide » si présent mais invalide ; sous-titres/titres/marqueurs inchangés (horloge globale, la coupe est sur la sortie).
