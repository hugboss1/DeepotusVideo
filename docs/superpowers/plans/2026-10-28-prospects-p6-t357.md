# Prospects P6 (t357) — WhatsApp pour la prospection : plan

> Exécution en natif (consigne du 28/10 : enchaîner t355 → t360). Spec :
> `docs/superpowers/specs/2026-10-27-agent-veille-prospection-design.md` §2, §3 (ligne WhatsApp) ; spec boîte à outils §6.3.
> Réutilise t310-t311 (`whatsapp`, `whatsapp_echanges`, `kapso`) sans en changer les règles. Suit t355 (séquences) et t356.

**But :** les étapes WhatsApp planifiées d'une séquence VALIDÉE partent par le numéro WhatsApp de l'espace, seulement
vers un contact qui a un accord enregistré ; les réponses du contact sont rattachées à sa fiche.

## Décisions (rulings)

1. **Toutes les règles restent celles de `whatsapp_echanges.envoyer`** (consentement d'un espace client, STOP, accord,
   fenêtre de 24 h, préférence marketing, accord SAISI pour un modèle marketing, plafond du mois, plafond de dépense) :
   la prospection n'a pas de chemin d'envoi à elle.
2. **Étapes** : une étape WhatsApp porte un MODÈLE approuvé {nom, langue, parametres} ; seul le 1er message peut être un
   texte libre, et il ne part que si la fenêtre de 24 h est ouverte au moment de l'envoi (sinon : arrêt « fenetre »).
   Les relances sont toujours des modèles (relecture t355, mineur 10 : hors fenêtre, Meta n'accepte qu'un modèle).
3. **Numéro d'envoi** : le compte WhatsApp de l'espace qui porte l'accord du contact ; aucun : arrêt « canal ».
4. **Coût** : un modèle est payant (Meta) : le devis et le plafond de dépense de `whatsapp_echanges` s'appliquent ;
   un refus de plafond (402) laisse l'étape planifiée et arrête la passe.
5. **Boucle** : avec celle de l'e-mail (toutes les 60 s), dans les heures calmes de l'espace.
6. **Réponses** : un message ENTRANT noté par `whatsapp.noter_entrant` dont l'identité correspond au canal WhatsApp
   d'une fiche de l'espace → contact entrant, Contactée → A répondu (la séquence s'arrête). Le texte n'est jamais rangé
   (règle t310) : l'agent le relit chez Kapso (P7). Un STOP passe déjà au registre (t353) → fiche opposée.
7. **Agent** : un outil de lecture `whatsapp_modeles` (modèles approuvés de l'espace : nom, langue, catégorie,
   paramètres) dans la boîte « prospects », pour remplir les étapes.

## Tâches

1. `prospects_sequences` : étapes WhatsApp avec modèle (validation de forme ; relances = modèle obligatoire).
2. `whatsapp_prospection.py` : compte de l'accord, envoi des étapes dues (refus → arrêt motivé, panne → 3 essais),
   branché dans la boucle ; crochet entrant → fiche. Banc `test_whatsapp_prospection.py` (faux envoyer).
3. Outil `whatsapp_modeles` ; schéma de `sequence_proposer` (modele) ; fixtures et comptes des bancs.
4. Écran : nom du modèle sur l'étape, motif « fenetre » ; i18n ; bancs node.
5. Connaissance, relecture, PR.
