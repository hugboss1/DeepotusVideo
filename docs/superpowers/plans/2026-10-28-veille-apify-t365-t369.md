## Règles communes (de la spec, valables pour chaque tâche)

- Toute collecte payante = une carte « collecte » (devis, plafond dur chez Apify : leads 1 $, veille 2 $), catégorie
  « campagnes », coût réel noté ; l'agent ne lance rien seul.
- LinkedIn exclu ; jamais d'e-mail deviné ni de vérificateur tiers ; jamais de DM ; auteurs hachés ; textes rendus
  ENCADRÉS comme preuves.
- Tout message d'erreur neuf → `scripts/i18n_l10_traductions.json` ; toute clé d'écran neuve en FR et EN ; la
  fixture `agent_definitions_campagnes.json` régénérée par `_agent_definitions_capture.py`.

## Décisions (rulings)

1. **Le « post-traitement » d'une collecte** dépend de la carte : `arguments.but` ∈ {`leads`, `veille`, `signaux`,
   `pubs`, `serp`} ; `_executer_collecte` appelle `apify_suite.traiter(but, …)` après le run (le dépôt JSON reste).
2. **t365 leads (A4)** : outil `entreprises_carte(categorie, ville, max≤100)` → carte `google_maps`
   (`searchStringsArray=[categorie]`, `locationQuery=ville`, `language=fr`). Après le run : des **cibles**
   {nom, site, note, categorie, ville} (sans téléphone ni avis), le **site de chaque cible déposé comme URL**
   (mêmes gardes que la recherche t354 : hôte public seulement) → `prospects_chercher(source="entreprise", url=site)`
   lit le site avec le lecteur t354 (robots.txt, e-mail publié revérifié). **Pas de `contacts_site`** : notre lecteur
   est gratuit et déjà revérifie (la spec l'autorise : « ou notre lecteur t354 ») ; l'entrée reste dans la liste
   blanche pour plus tard.
3. **t366 veille enrichie (A2)** : le périmètre gagne, par concurrent, un objet facultatif `apify` {source: [valeurs]}
   (sources : reddit, x, instagram, instagram_posts, tiktok, tiktok_commentaires, avis_google_maps, google_play,
   trustpilot, g2 ; 5 valeurs au plus, 300 caractères) ; outil `veille_apify(source, concurrent, max)` → carte avec
   l'entrée tirée du périmètre (jamais inventée par l'agent). Après le run : conversion en lignes de veille (champs de
   `apify_vers_brut.py` portés dans `apify_suite.CHAMPS`, auteur haché), écrites dans
   `veille/<eid>/<date du jour>/brut/apify-<source>-<concurrent>.jsonl` (dédoublonnées), puis `_consolider` (classées
   par `veille_grille`) — sauf si une collecte tourne : elle consolidera à sa fin.
4. **t367 signaux Reddit (A5)** : outil `signaux_reddit(requetes≤5, communaute?, max)` → carte `reddit` (but
   `signaux`). Après le run : seuls les posts qui expriment un BESOIN (« alternative à », « combien coûte », « je
   cherche », « recommend », « looking for »…) sont gardés comme signaux {url, extrait ≤ 300, date, auteur_hash},
   rangés dans `prospects/<eid>/signaux_reddit.json` (30 jours) ; `prospects_chercher(source="veille")` les rend avec
   ceux de la veille et la règle de réponse publique. Jamais une fiche.
5. **t368 concurrents (A3)** :
   - **pages prix / fonctions** (gratuit) : périmètre `pages` (3 URL au plus par concurrent) ; outil
     `concurrents_pages()` lit chaque page (robots.txt, cadence du lecteur t354), garde le texte et rend le DIFF avec la
     lecture précédente (`veille/<eid>/pages/<concurrent>/`), encadré ;
   - **pubs actives** : Actor `facebook_pubs` (`apify~facebook-ads-scraper` 0.0.392, 0,0058 $/pub, enrichissement
     e-commerce coupé) ; périmètre `facebook` (URL de page) ; outil `concurrents_pubs(concurrent, max)` → carte (but
     `pubs`) → `veille/<eid>/concurrents/pubs-<concurrent>.json` {texte, debut, plateformes, lien} ;
   - **positions SERP** : Actor `serp` (`apify~google-search-scraper` 0.0.474, 0,0045 $/page ; IA, leads, contenu des
     sites coupés) ; périmètre global `mots_cles` (10 au plus) et `domaine` par concurrent ; outil
     `concurrents_serp(max)` → carte (but `serp`) → `veille/<eid>/concurrents/serp.json` {mot_cle: [{rang, domaine,
     concurrent?}]} ;
   - **volet « Concurrents »** de l'onglet Veille : `GET /api/veille/{eid}/concurrents` (pubs, pages changées, SERP) et
     son affichage (lecture seule).
6. **t369 clôture (A6)** : chapitre `prospection` du guide (leads Google Maps, signaux Reddit) et `veille` (sources
   Apify, volet Concurrents) en FR/EN, clés i18n, fiches du catalogue de l'assistant, AGENT.md à taille constante.
